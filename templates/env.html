Auf dem Host selbst ist es ein Befehl im Verzeichnis deploy/:

docker compose --profile panel up -d

Wer ihn nicht tippen will, legt ihn auf dem Host in eine Datei und verknüpft sie: ein Doppelklick tut dasselbe. Eine Sicherheitskopie der Datei von vor der Änderung liegt auf dem Server-Volume unter panel/env-history/, die letzten zehn.
